# Vishwas deck design system

Extracted from the product's own tokens in `frontend/index.html` (`:root`) and adapted for the SIH 2026 idea-PPT template, so the deck and the running console read as one product.

## Colour

| Role | Token | Hex | Where it comes from |
|---|---|---|---|
| Ink / dominant | `navy` | `#0C2340` | `--navy`, `--ink`: titles, dark bands, header tabs |
| Primary | `blue` | `#1A4E9B` | `--blue`: key numbers, primary headers |
| Secondary | `steel` | `#2C6DB0` | `--steel`: pipeline steps |
| Tint | `sky` | `#EAF2FA` | `--sky`: ribbons, stat tiles, table label column |
| Hairline | `line` | `#C9D3E0` | `--line`: card borders |
| Body text | `text` / `muted` | `#1D2733` / `#566476` | `--text`, `--muted` |
| Sharp accent | `saffron` | `#F58220` | landing-page step accent: Sarvam, "innovation", proof labels |
| ML / data | `teal` | `#167A83` | `--teal`: the AI/ML engine |
| Model Trust only | `violet` | `#5B3FA0` | `--violet`: never used for warnings, same rule as the console |

**IMD warning scale (semantic, never decorative):** Green `#1E7A3C` · Yellow `#F2B300` · Orange `#E8720C` · Red `#C62828`. Use it only where it means a warning level, as the console does.

Soft tints for card fills: teal `#E3F2F3`, saffron `#FEF0E4`, green `#E6F2EA`, red `#FDECEC`, violet `#EFEBF8`.

## Type

- **Titles:** the SIH template's serif title placeholder (bold, navy, 30–34 pt), kept for template compliance.
- **Everything else:** Arial (the console uses Noto Sans; Arial is the Office-safe equivalent). Header tabs 11.5–12.5 pt bold white; card titles 10.5–11.5 pt bold navy; body 9–10.5 pt; big numbers 18–26 pt bold.
- **Devanagari:** Nirmala UI (Windows / Office), set as the complex-script font on every Hindi run.

## Layout (13.33 × 7.5 in template)

- Keep the template's team oval (top left), SIH logo (top right) and blue footer bar.
- Title band sits between the oval and the logo (x 1.85–10.6 in). A one-line **sky ribbon** under it (bold blue lead-in + navy sentence) states the slide's claim.
- Content zone: y 1.62–6.84 in, 0.4 in side margins, 0.1–0.2 in gutters.

## Motifs

1. **Header-tab cards:** a rounded card whose top is a solid colour tab with a white icon and an uppercase label. One colour per column's role (red = problem, navy = product, saffron = innovation/Sarvam, teal = ML, green = sustainability).
2. **Icons in solid circles** (Font Awesome 6 via react-icons, rendered white on the role colour).
3. **Numbered circles** for ranked lists (USPs, roadmap, references).
4. **Pill chips** for categories, IMD levels and timeline states.
5. **Navy proof band** for the out-of-sample evidence (Chennai 2015).

## Imagery

- Real product screenshots (from `docs/screenshots/`) with a hairline border instead of mock-ups.
- Diagrams (`architecture.png`, `sarvam.png`, `loop.png`) are drawn as SVG in these same tokens and rendered at about 300 dpi. They are regenerated by `images.js` in the build folder.
